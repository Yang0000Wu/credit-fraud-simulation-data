# Credit Fraud Simulation Data · 银行级全体系模拟仿真数据集

> 银行级消费金融反欺诈模拟仿真数据集（信贷申请 + 全生命周期行为），用于风控模型训练与验证。
> **100% 合成数据，不包含任何真实个人信息，仅供算法测试。**

## 📦 本仓库内容（免费开源样本）

**《080-万象》同源切片**——100 客户，五种欺诈手法全覆盖（身份冒用 / 包装贷骗贷 / 第一方违约 / 团伙欺诈 / 合成身份）

- **规模**：100 客户 × 1,681 笔行为事件（注册→申请→放款→套现→违约全流程）
- **结构**：客户表 + 行为事件流水 + 设备表，按 `customer_id` 关联
- **标签**：`risk_label` 六分类（normal + 5 类欺诈），每个欺诈手法样本中真实可见

| 文件 | 说明 |
|---|---|
| `sample_data/transactions_sample.csv` | 1,681 笔行为事件流水（原始序列） |
| `sample_data/users_sample.csv` | 100 客户画像与欺诈标签（16 字段） |
| `sample_data/devices_sample.csv` | 设备汇总表 |
| `sample_data/data_dictionary.md` | 全字段详解、标签语义与建模口径 |
| `scripts/make_samples.py` | 同源切片脚本（seed=42，可复现，100% 合成证明） |

关键字段速览：`risk_label`（欺诈标签）· `event_type`（事件类型：apply/disburse/cashout/…）·
`device_id` · `ip_city`/`declared_city`（地理一致性）· `action`（中文行为描述）

欺诈剧本特征样本中直接可观察：放款后短时间多笔集中提现（cashout）、异地申请、模拟器/越狱设备——
适合快速验证 XGBoost/LightGBM/时序模型/异常检测，或教学演示。

> **样本与完整版同字段、同口径、同一生成体系**——样本上验证的代码可直接迁移到完整版。
