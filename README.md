# Credit Fraud Simulation Data · 全场景风控仿真数据集

> 银行级**全场景风控模拟仿真数据集**（金融 / 网络安全 / 保险），用于风控模型训练与验证。
> **100% 合成数据，不包含任何真实个人信息，仅供算法测试。**
> 三大产品线均含：免费开源样本 + 完整版（L3 攻击链/欺诈链标注 + L4 对抗变体）。
